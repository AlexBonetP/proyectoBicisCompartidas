# proyectoBicisCompartidas
# 🚲 Sistema de Gestión de Bicicletas Compartidas — Modelo y Backend SQL

Este repositorio contiene el diseño y la implementación de un sistema de gestión para un servicio de bicicletas compartidas, inspirado en plataformas reales como Bicing Barcelona. El proyecto abarca el ciclo completo de diseño del modelo de datos, creación del esquema SQL y programación de la lógica interna del sistema.

## 🔧 Tecnologías utilizadas
- MySQL Workbench  
- MySQL Server  
- SQL estándar  

## 🧱 Arquitectura del proyecto
El desarrollo se organiza en tres fases independientes:

- **Fase 1 — Diseño del modelo de datos**  
  Modelado conceptual y físico, diagrama ER y definición de entidades y relaciones.

- **Fase 2 — Implementación del esquema SQL**  
  Creación de tablas, claves primarias, claves foráneas, restricciones e integridad referencial.

- **Fase 3 — Programación de lógica interna**  
  Procedimientos almacenados, triggers, eventos, inserciones de datos y reglas de negocio.

## 📦 Estructura del repositorio
/fase1_disenyo/          → Modelo .mwb y diagramas
/fase2_implementacion/   → Esquema SQL
/fase3_programacion/     → Triggers, procedures, events, inserts
/docs/                   → Documentación ampliada
README.md                → Este archivo


## ▶️ Cómo ejecutar el proyecto
1. Crear el esquema en MySQL  
2. Importar el archivo SQL correspondiente  
3. Ejecutar los scripts de programación según la fase
